## ⚡ Core Platform Capabilities

* **0.00 Paisa Reverse-GST Math:** Eliminates ledger rounding drift on MRP-inclusive consumer retail sales[cite: 9, 10].
* **Serialized IMEI / Barcode Lifecycle:** End-to-end device tracking from purchase intake (GRN) to POS checkout, warranty return, and Defective RTV[cite: 9, 10].
* **Multi-Tender Settlements:** Integrated split payments for Cash, UPI/QR, Cards, and Consumer Finance EMI loans (Bajaj Finserv, TVS Credit, IDFC First)[cite: 9, 10].
* **Multi-Counter Concurrency:** Database atomic sequence locks guarantee zero invoice collisions or duplicate bill numbering across lanes[cite: 1, 9, 10].
* **Counter Security:** 30-second background inactivity PIN lock keeps unattended terminals secure without losing uncommitted cart items[cite: 1, 9, 10].

## 🚀 Installation & Update Instructions

### Windows Desktop Setup
1. Download `SyantrexERP_Setup.exe` from the latest release[cite: 2, 15].
2. Run the installer and follow the on-screen setup wizard[cite: 2, 15].
3. Launch **Syantrex ERP** from your desktop or start menu shortcut[cite: 2, 5].
4. **Automatic Updates:** When a new release is published, the app displays an **"UPDATE NOW"** prompt upon launch to install updates automatically[cite: 15].

### Android Installation
1. Install directly via the [Google Play Store](https://play.google.com/store/apps/details?id=com.syantrex.erp)[cite: 19].
