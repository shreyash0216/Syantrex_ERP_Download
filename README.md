## ⚡ Core Platform Capabilities

* **0.00 Paisa Reverse-GST Math:** Eliminates ledger rounding drift on MRP-inclusive consumer retail sales.
* **Serialized IMEI / Barcode Lifecycle:** End-to-end device tracking from purchase intake (GRN) to POS checkout, warranty return, and Defective RTV.
* **Multi-Tender Settlements:** Integrated split payments for Cash, UPI/QR, Cards, and Consumer Finance EMI loans (Bajaj Finserv, TVS Credit, IDFC First).
* **Multi-Counter Concurrency:** Database atomic sequence locks guarantee zero invoice collisions or duplicate bill numbering across lanes.
* **Counter Security:** 30-second background inactivity PIN lock keeps unattended terminals secure without losing uncommitted cart items.

## 🚀 Installation & Update Instructions

### Windows Desktop Setup
1. Download `SyantrexERP_Setup.exe` from the latest release.
2. Run the installer and follow the on-screen setup wizard.
3. Launch **Syantrex ERP** from your desktop or start menu shortcut.
4. **Automatic Updates:** When a new release is published, the app displays an **"UPDATE NOW"** prompt upon launch to install updates automatically.

### Android Installation
1. Install directly via the [Google Play Store](https://play.google.com/store/apps/details?id=com.syantrex.erp).
2. Alternatively, download the `.apk` file, enable *Install unknown apps* on your device, and proceed with installation.
